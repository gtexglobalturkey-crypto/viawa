# Participation Opportunity Specification
Version: 1.0
Status: MVP
Owner: Atlas Representative

---

# Purpose

A Participation Opportunity represents one exhibition participation process.

Each exhibition participation starts with a new opportunity and ends independently.

A company may have multiple Participation Opportunities.

Example:

Atlas Mining

- Dubai Mining 2027 ✅
- Kazakhstan Mining 2027 ✅
- Mongolia Mining 2028 ✅

These opportunities are completely independent from each other.
